# pairwise-rope-constraint

吊桥被炮弹炸断后，绳索像面条一样拉长，末端还穿进地面：绳索约束按固定 8 次迭代，质量比差太大时收敛不了；质点距离约束只修正位置，没有修正速度，能量越积越大；绳索和角色碰撞只做点测试，快速摆动时穿过身体；风力和重力在同一积分步叠加，强风下绳索抖动；绳索长度约束在断裂后没有重新分配，断口处拉长；子步按固定 4 步，低帧率时约束爆炸；网络同步只发端点，整条绳的形状在客户端各自模拟；不同材质段的阻尼一样，铁链和麻绳手感相同；绳索与静态网格的碰撞法线取反，末端弹进地面；约束求解顺序按数组顺序，结果不可复现；拉伸超过阈值才断开，但阈值用的是世界距离，缩放后误判；绳索的包围盒没随形状更新，视锥剔除把整条绳剔掉；GPU 和 CPU 各算一套约束，渲染位置和物理位置错位。physics/rope_constraint.py 是核心，tests/test_rope_constraint.py 15个红。要修的是：质量比预处理；位置速度双修正；扫掠碰撞；风力分离；断后重分配；自适应子步；网络形状同步；分段阻尼；碰撞法线；确定性顺序；局部阈值；包围盒更新；CPU/GPU 一致。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
